# 耐久ボード

配信の耐久企画で使える画像を作成する、GitHub Pages向けの静的サイトです。

## ローカルで使う

`index.html` をブラウザーで開くと利用できます。サーバーで確認する場合は `start.bat` を実行し、http://localhost:8080 を開いてください（Pythonが必要です）。

- 47都道府県の達成チェック、地域別表示、名前検索
- タイトル・サブタイトル・配信者名の編集
- 5つの配色、横長・正方形・縦長の画像
- PNG保存、透明背景
- ブラウザー内への設定・達成状況の自動保存

保存画像はプレビューと同じCanvasから生成します。通信やAPIキーは不要です。保存状況はブラウザーとURLごとに異なります。ローカルファイルでの設定保存はブラウザーによって制限されることがあります。

12星座耐久も利用できます。干支耐久も利用できます。

## GitHub Pagesへのアップロード（公開するとき）

1. このフォルダーのファイルをGitHubリポジトリの公開対象ブランチへアップロードします。
2. リポジトリの Settings → Pages で「Deploy from a branch」を選びます。
3. 対象ブランチの `/ (root)` を指定して保存します。

ビルドは不要です。相対パスを使用しているので、リポジトリ名の付いたURLにも対応します。

## 構成

- `index.html`: 画面
- `style.css`: レイアウト
- `app.js`: 都道府県データ、操作、Canvas描画、PNG出力

画像や外部ライブラリ・外部フォントには依存していません。日本地図と地域別リストの両方に対応します。

## 縦長・日本地図表示

初期表示はスマホ配信向けの縦長 1080 × 1920（9:16）です。「日本地図＋都道府県一覧」と「地域別リスト」を切り替えられます。地図や画像内の県名をタップすると、達成状況と編集側の一覧が連動します。小さい県は編集側の県名ボタンからも選べます。

旧版の達成データは引き継ぎ、初回のみ縦長・地図表示へ切り替えます。その後のサイズ・表示設定は保存されます。

### 地図データ

`map-data.js` は [open-data-jp-prefectures-geojson](https://github.com/piuccio/open-data-jp-prefectures-geojson) の国土数値情報由来の境界データを簡略化したものです。MITライセンスは `MAP-LICENSE.txt` に同梱しています。沖縄は別枠へ移動し、一部離島は省略した配信用の概略図です。出典とライセンスはこのREADMEおよび同梱のライセンスファイルに記載しています。

`build-map.py` は開発用の変換スクリプトです。再生成する場合は元リポジトリの `output/prefectures.geojson` を `prefectures-source.geojson` として配置して実行します。サイトの利用時は不要です。

## 人数とカウント条件

達成条件は各都道府県共通で初期値1人、1〜99999人の整数で設定できます。各県は＋・−または数値入力で0〜99999人を記録できます。地図や画像内の県名のタップは＋1人です。人数が達成条件以上になると自動で達成色になります。条件人数を変更しても記録人数は保持します。「すべて達成」は不足する県だけ条件人数まで増やし、「人数をすべて0に」は全県を0人にします。

カウント条件は自由入力です。入室 / フォロー / バッジ獲得 / バッジ獲得 or 進化 / ギフト「(ギフト名)」の候補もあります。ギフト名は実際の名前に書き換えて使います。条件と各県の現在人数／必要人数はPNGにも表示します。旧版の達成チェックは1人として引き継ぎます。タイトル・サブタイトル・配信者名の入力と出力は廃止しました。現在の設定と人数はブラウザーに自動保存します。

## カウント条件の画像

「カウント条件：」と条件テキストの間に、文字と同じ高さの画像を表示します。画像未設定時は条件に応じた標準アイコン（入室・フォロー・バッジ・進化・ギフト・自由入力）を表示します。「カウント条件の画像」からPNG・JPEG・WebP・GIFを指定できます。画像は縦横比を保ち128px四方へ縮小し、設定とともにブラウザー内に保存します。「標準アイコンに戻す」で解除できます。プレビューとPNG出力の両方に反映します。


## 画像の表示・共有

「画像を表示・共有」で保存用画像を開きます。スマホでは画像の長押しで保存でき、ファイル共有に対応する端末では「画像を共有」ボタンから共有メニューを開けます。非対応の環境では「画像をダウンロード」を利用できます。

## 救済・妨害ギフト

ボード設定の「ギフトでの救済・妨害」でそれぞれ表示を有効にし、ギフト名を入力できます。両方が設定されたルールだけ画像下部に表示します。救済は任意の都道府県を＋1、妨害は−1です。ルールはブラウザー内に保存されます。ギフトの受信を自動検知する機能はなく、対象県の＋・−で手動反映します（0未満にはなりません）。

救済・妨害ルールにはそれぞれ画像を設定できます。各設定内のファイル選択で画像を指定すると、画像内のルール文の左に文字と同じ高さで表示します。PNG・JPEG・WebP・GIFに対応し、縦横比を保って縮小保存します。画像はブラウザーに保存され、「画像を解除」で個別に削除できます。ルールが無効、またはギフト名が空の場合は画像も表示されません。

## 12星座耐久

`zodiac.html` に12星座耐久を追加しました。上部の企画選択から切り替えられます。星座カードとシンプル一覧、人数の記録、達成人数・カウント条件、画像のトリミング、救済・妨害、達成・未達成時の内容、画像表示・共有に対応します。星座の記号は黄道12星座のシンボルです。設定と人数は都道府県版と独立して保存します。保存画像名は `12星座耐久_mmdd_hhmmss.png` です。


## 干支耐久

`eto.html` で子・丑・寅・卯・辰・巳・午・未・申・酉・戌・亥の十二支に対応します。動物マーク付き円形図と一覧、カウント、条件設定、画像設定・トリミング、救済・妨害、保存・共有を利用できます。設定は都道府県・12星座とは別に保存します。

## 誕生月・MBTI耐久

`month.html` は1〜12月の誕生月耐久、`mbti.html` はINTJ・INTP・ENTJ・ENTP・INFJ・INFP・ENFJ・ENFP・ISTJ・ISFJ・ESTJ・ESFJ・ISTP・ISFP・ESTP・ESFPの16タイプ耐久です。誕生月は円形図と一覧、MBTIはカード一覧で表示します。人数記録・条件設定・画像設定・救済と妨害・画像保存と共有に対応し、設定は各企画で独立して保存します。MBTIページは申告されたタイプを記録するもので、診断機能はありません。

MBTIの各タイプには内蔵ImageGenで生成したオリジナルキャラクターを表示します。`assets/mbti-original.png` は4×4の背景透過スプライトシートで、タイプ順に切り出してCanvas上に描画します。制作プロンプトは `assets/mbti-original.prompt.txt` に記録しています。画像はイメージ表現です。
